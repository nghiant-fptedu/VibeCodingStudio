# VibeSpace - Backend Source Code

Thư mục này được chuẩn bị sẵn trong cấu trúc Monorepo để chứa mã nguồn backend trong tương lai (REST API, WebSocket, Authentication, Cloud Sync, hoặc Database services).

### Hướng dẫn khởi tạo khi phát triển backend:
- Bạn có thể khởi tạo backend service tại đây (ví dụ: Node.js/Express, NestJS, Fastify, Go, Python/FastAPI,...).
- Nếu sử dụng Node.js, khởi tạo `package.json` với tên `@vibespace/backend` để tự động tích hợp vào npm workspaces của Monorepo.
